# Task 1: Logical & Conditional Functions

## Project Overview
This project focuses on applying Excel logical and conditional functions to perform decision-making and classify data based on specified conditions. It uses logical tests and error-handling functions to evaluate spreadsheet values.

## Objectives
- Apply IF, IFS, AND, OR, and NOT functions.
- Implement nested IF conditions.
- Use CHOOSE and SWITCH for alternative lookups.
- Handle errors and blank cells.

## Functions Covered
IF, IFS, AND, OR, NOT, Nested IF, CHOOSE, SWITCH, ISERROR, ISBLANK, ISNUMBER.

## Expected Outcome
Develop the ability to evaluate multiple conditions, automate logical decisions, and handle different data situations using Excel formulas.
