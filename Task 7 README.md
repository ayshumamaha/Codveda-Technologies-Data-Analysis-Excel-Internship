# Task 1: Power Query for Data Transformation

## Project Overview
This project focuses on using Excel Power Query to automate data extraction, transformation, and loading (ETL). It demonstrates how data can be imported from different sources, cleaned, combined, and reshaped for analysis.

## Objectives
- Connect to and import external data sources.
- Merge and append queries.
- Split and transform columns.
- Group and reshape data.
- Automate data refresh operations.

## Tools and Features Covered
Power Query, Data Import, Query Merging, Query Appending, Column Splitting, Grouping, Data Shaping, Refresh.

## Expected Outcome
Develop the ability to automate data preparation workflows and manage data from multiple sources using Power Query.
