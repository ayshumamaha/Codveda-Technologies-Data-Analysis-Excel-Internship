# Task 4: Data Cleaning & Preprocessing

## Project Overview
This project focuses on preparing raw spreadsheet data for analysis by identifying and correcting inconsistencies. It uses Excel tools and functions to remove duplicate records, handle blank values, standardize text, and transform data into a consistent format.

## Objectives
- Clean raw datasets.
- Remove duplicate and blank records.
- Standardize inconsistent text.
- Transform data into usable formats.

## Tools and Functions Covered
Remove Duplicates, TRIM, CLEAN, SUBSTITUTE, Text to Columns, Flash Fill, Find and Replace.

## Expected Outcome
Develop the ability to prepare accurate and consistent datasets for further analysis and reporting.
