# Task 2: Advanced Lookup & Reference Functions

## Project Overview
This project explores advanced Excel lookup and reference functions to retrieve and cross-reference information from structured datasets. It focuses on flexible lookup methods and dynamic references for efficient data analysis.

## Objectives
- Retrieve data using advanced lookup functions.
- Compare and cross-reference datasets.
- Apply flexible reference techniques.
- Select dynamic ranges for analysis.

## Functions Covered
VLOOKUP, HLOOKUP, XLOOKUP, INDEX-MATCH, INDIRECT, OFFSET.

## Expected Outcome
Develop the ability to retrieve relevant information efficiently and perform flexible lookups across large datasets.
