# Task 6: Statistical & Data Analysis

## Project Overview
This project applies statistical functions and analytical techniques in Excel to examine datasets, identify relationships, and evaluate differences between groups. It covers descriptive statistics, regression, hypothesis testing, correlation, and covariance.

## Objectives
- Calculate descriptive statistical measures.
- Perform regression analysis.
- Conduct statistical hypothesis tests.
- Examine relationships between variables.
- Interpret analytical results.

## Functions and Tools Covered
Mean, Median, Mode, Variance, Standard Deviation, Regression Analysis, t-Test, Chi-Square Test, ANOVA, Correlation, Covariance, Analysis ToolPak.

## Expected Outcome
Develop practical skills in statistical analysis and data-driven interpretation using Excel.
