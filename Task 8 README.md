# Task 8: Power Pivot & Data Modeling

## Project Overview
This project explores Excel Power Pivot for building relational data models and performing advanced calculations using DAX. It focuses on connecting multiple datasets, creating relationships, and developing measures and calculated columns for business analysis.

## Objectives
- Create relational data models.
- Establish relationships between datasets.
- Write DAX formulas.
- Develop measures and calculated columns.
- Build interactive KPI metrics.

## Tools and Features Covered
Power Pivot, Data Modeling, DAX, Relationships, Measures, Calculated Columns, KPI Metrics.

## Expected Outcome
Develop the ability to manage connected datasets and perform advanced analytical calculations using Power Pivot.
