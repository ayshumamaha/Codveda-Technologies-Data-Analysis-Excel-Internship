# Task 9: Scenario & What-If Analysis

## Project Overview
This project focuses on Excel What-If Analysis tools for evaluating alternative business scenarios and understanding how changes in input values affect results. It includes target-based calculations, multi-variable forecasting, scenario comparisons, and simulation-based risk assessment.

## Objectives
- Perform target-based analysis using Goal Seek.
- Evaluate multiple variables using Data Tables.
- Compare alternative business scenarios.
- Conduct risk assessment through Monte Carlo Simulation.

## Tools and Features Covered
Goal Seek, Data Tables, Scenario Manager, Monte Carlo Simulation.

## Expected Outcome
Develop the ability to evaluate possible outcomes, perform sensitivity analysis, and support decision-making using Excel What-If Analysis tools.
