# Task 3: Array Formulas & Dynamic Arrays

## Project Overview
This project focuses on Excel array formulas and dynamic array functions to automate calculations and manage datasets efficiently. It demonstrates how formulas can generate, filter, sort, and rearrange multiple values.

## Objectives
- Understand dynamic array functionality.
- Automate data extraction and organization.
- Perform advanced data aggregation.
- Work with array formulas in Excel.

## Functions Covered
SEQUENCE, UNIQUE, SORT, FILTER, TRANSPOSE, SUMPRODUCT, and legacy CSE array formulas.

## Expected Outcome
Gain practical knowledge of dynamic arrays and advanced formulas for handling and analyzing spreadsheet data.
