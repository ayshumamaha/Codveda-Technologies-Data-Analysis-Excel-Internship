# Task 5: Pivot Tables & Pivot Charts

## Project Overview
This project explores Excel Pivot Tables and Pivot Charts for summarizing, analyzing, and visualizing large datasets. It focuses on organizing information through multiple fields and creating interactive reports.

## Objectives
- Create and modify Pivot Tables.
- Summarize data using multiple fields.
- Perform custom calculations.
- Build interactive visualizations.

## Tools and Features Covered
Pivot Tables, Calculated Fields, Slicers, Timelines, Pivot Charts.

## Expected Outcome
Develop the ability to summarize large datasets, identify trends, and present findings through interactive Excel reports.
